# UI/UX AirdropHunter

- Identitas: panel kerja yang matang, informasi jelas dan padat secukupnya. Tanpa hero marketing, grafik dekoratif, atau statistik/reward palsu; angka dihitung dari data tersedia.
- Token: latar `#0E1218`, permukaan `#171E27`, garis `#2B3543`, teks `#E6EDF5`/`#A8B5C7`, aksen hijau `#91D962` untuk aksi utama dan sukses, amber untuk peluang, ungu khusus label DEMO. Hijau bukan satu-satunya pembeda status: selalu ikon + teks. Ukur kontras pada pasangan warna aktual.
- Font system; angka tabular; alamat dan chain ID monospace. Radius sedang, bayangan ringan, satu skala spacing.
- Desktop: header (nama aplikasi, jaringan, akun, Cari airdrop), sidebar fitur yang tersedia saja, panel scan, filter, tabel (proyek, jaringan, status untuk wallet, tenggat, aksi), detail dalam drawer.
- HP: navigasi ringkas di bar bawah dengan Cari airdrop, daftar kartu, detail layar penuh dengan aksi tetap terlihat, target sentuh ±44 px, safe area, alamat dipersingkat dan dapat disalin/dilihat penuh.
- Perilaku: setiap tombol beraksi atau menjelaskan alasannya; scan menampilkan progres, sumber selesai, hasil sebagian, Batalkan, Coba lagi; keadaan kosong memberi langkah lanjut; error spesifik dan dapat dipulihkan; cegah klik ganda; animasi ringan dan hormati `prefers-reduced-motion`.
- Aksesibilitas: elemen native, label input, fokus terlihat, keyboard penuh, dialog dapat ditutup dan mengembalikan fokus, live region untuk loading/hasil. Jangan menonaktifkan zoom. Build lulus tidak membuktikan UI bagus atau aksesibel.
